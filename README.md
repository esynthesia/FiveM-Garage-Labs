# FiveM Custom Vehicle Pack

A FiveM resource package containing custom vehicle files, including metadata configurations and streaming 3D assets.

## Repository Structure
- `fxmanifest.lua` - FiveM resource manifest file.
- `data/` - Vehicle configuration files (`vehicles.meta`, `carcols.meta`, `handling.meta`, `carvariations.meta`).
- `stream/` - Folder containing 3D model files (`.yft`, `.ytd`).

## Installation
1. Download or clone this repository into your server's `resources` directory.
2. Add `ensure [Vehicles]` to your `server.cfg` file.
3. Restart your server.
